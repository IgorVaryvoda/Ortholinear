# Keyboard appearance

Open **Settings → Appearance → Theme and colors**. Appearance is the first section; layout controls are grouped into Presets, Size, Spacing, and Controls, followed by optional letters and typing preferences. Theme changes update the keyboard immediately, preserve geometry, and save through the same local App Group settings as the rest of the keyboard. Dismiss and reopen the system keyboard to load changed settings.

Seven choices are included: Automatic (follows the device), Warm Light, Soft Dark, High Contrast, Tokyo Night, Catppuccin Mocha, and Nord. The accent can follow the theme or use teal, blue, purple, rose, or amber. Long-press hints can be turned off independently.

## Palette references

The named themes adapt these original palettes to keyboard surfaces. Hint colors are adjusted where needed to preserve contrast during presses.

- [Tokyo Night](https://github.com/folke/tokyonight.nvim): Night background with Storm surface, foreground, and blue accent colors.
- [Catppuccin](https://github.com/catppuccin/palette): Mocha base, mantle, surface, text, and mauve.
- [Nord](https://www.nordtheme.com/docs/colors-and-palettes/): Polar Night, Snow Storm, and Frost.

The core contrast checks cover letters and hints on normal and pressed keys for every theme/accent combination. High Contrast follows the device’s light/dark mode and uses stronger outlines; the system’s Increase Contrast setting also strengthens outlines and hint text in every theme. Reduce Motion keeps brief static feedback instead of a fade.
